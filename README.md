## How to choose a plan size

The plan names correspond to storage size, but storage alone is a poor way to choose a VPS. Consider the full resource set:

- **40G, 2 GB RAM:** A starting point for a small service or development environment, assuming the software and workload fit comfortably within 2 GB of memory.
- **80G, 4 GB RAM:** More room for a modest application stack, a small database, or multiple lightweight services.
- **160G, 8 GB RAM:** A larger allocation for workloads that need more memory or generate more data.
- **320G and above:** Intended for workloads with higher resource or transfer requirements. The monthly cost rises quickly, so estimate the actual bottleneck before buying.
- **640G and 1280G:** Large configurations with 32 GB or 64 GB RAM and up to 8 TB monthly transfer. They are difficult to justify for a small website; consider them when measured resource use supports the spend.

These are workload-planning guidelines, not performance guarantees. Application behavior depends on the operating system, software stack, traffic patterns, and configuration. If you are migrating an existing service, use its monitoring data to estimate memory use, disk consumption, and monthly transfer instead of sizing from guesswork.

For a new project, a smaller plan can be a reasonable way to begin if the provider’s upgrade and migration options meet your needs.
